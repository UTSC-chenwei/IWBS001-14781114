# The Corner Cafe - Website Requirements

## Top 3 Priority Requirements

- [ ] Display opening hours on every page.
- [ ] Show a menu with breakfast, lunch, drinks and prices.
- [ ] Make the website friendly and easy to read.

## Other Requirements

- [ ] Create a welcoming Home page with cafe photos.
- [ ] Highlight weekly specials.
- [ ] Include the cafe address, map and contact details.
- [ ] Use warm and friendly colors throughout the website.
